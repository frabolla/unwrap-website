Domande frequenti

  • Cos'è un file .p7m (o .m7m)? Un file .p7m è un documento (PDF, fattura elettronica, XML, immagine…) racchiuso in una «busta» firmata digitalmente secondo lo standard CAdES/PKCS#7, usato in Italia e in Europa per fatture elettroniche, PEC, contratti e atti della Pubblica Amministrazione. Un file .m7m è invece un contenitore che abbina al documento una o più marche temporali (RFC 5544). Unwrap apre entrambi e mostra subito il contenuto.

  • Quali tipi di file, formati e verifiche è in grado di aprire l'applicazione? (Dettagli tecnici)

    Unwrap analizza direttamente i byte del file (fino a 256 MB) anziché fidarsi della sola estensione, ed è progettata per gestire buste crittografiche, fatture elettroniche, messaggi di posta e documenti d'ufficio:

    1. Buste firmate e contenitori

    Apre buste .p7m (CAdES / PKCS#7 SignedData) nelle codifiche DER binaria, Base64 e PEM, incluse le strutture BER a lunghezza indefinita.

    Gestisce buste annidate (es. .pdf.p7m.p7m) fino a 5 livelli mostrando i firmatari di ciascuna busta, firme detached (buste con sola firma, verificando crittograficamente che il file originale scelto dall'utente sia proprio quello firmato), contenitori marcati temporalmente .m7m (TimeStampedData, RFC 5544) e firme CAdES-T. Supporta algoritmi RSA, RSA-PSS ed ECDSA. (Le buste cifrate EnvelopedData non sono supportate).

    2. Fatture elettroniche (IT ed UE)

    FatturaPA (Italia): fatture ordinarie, verso la PA e semplificate (FPR12, FPA12, FSM10), impaginate in A4 con i fogli di stile XSLT ufficiali AssoSoftware o Agenzia delle Entrate, oppure consultabili come XML originale.

    Formati europei (EN 16931 e nazionali): impaginazione A4 integrata (senza download esterni) per UBL 2.1 (rete Peppol BIS 3.0, XRechnung UBL, OIOUBL, RO e-Factura, anche in busta Peppol SBDH), UN/CEFACT CII (XRechnung CII, Francia), Factur-X / ZUGFeRD 1.0 e 2.x (anche estraendo l'XML incorporato nei PDF ibridi su Mac, Windows e iOS), Facturae 3.2.x (Spagna, inclusi i lotti multi-fattura) e KSeF FA(2)/FA(3) (Polonia).

    3. Email, PEC e documenti estratti

    Email e PEC (.eml, postacert.eml): legge intestazioni, testo (in una vista isolata senza script né immagini remote), dati di certificazione PEC (daticert.xml) e permette di aprire tutti gli allegati.

    Formati visualizzati direttamente: PDF (zoom, miniature, ricerca, stampa), XML e JSON (formattati con indentazione e sintassi colorata), testo (UTF-8, UTF-16 con BOM, Windows-1252) e immagini (PNG, JPEG, GIF, BMP, WebP, HEIC/AVIF fino a 40 MP). Qualsiasi altro formato viene estratto per essere salvato o aperto con l'app predefinita, con blocco di sicurezza contro l'avvio involontario di eseguibili o script (.exe, .bat, .apk, .sh).

    4. Verifiche crittografiche (su richiesta)

    Integrità e catena di fiducia: verifica l'impronta crittografica (digest) e la firma matematica del documento; ricostruisce la catena dei certificati (scaricando eventuali intermedi via AIA) fino alle radici di sistema o alle Trusted List ufficiali eIDAS (lista italiana AgID o liste di tutta l'UE, comprese le serie storiche dei servizi qualificati).

    Idoneità, revoca e marche temporali: controlla l'uso consentito del certificato (Key Usage / EKU), interroga i servizi OCSP e CRL per verificare lo stato di revoca, e valida le marche temporali (CAdES-T e .m7m, inclusi metadati protetti e catene di marche successive). La verifica ha valore tecnico informativo e non sostituisce una validazione legale LTV.

FAQ

  • What is a .p7m (or .m7m) file? A .p7m file is a document (PDF, e-invoice, XML, image…) wrapped in a digitally signed “envelope” following the CAdES/PKCS#7 standard, widely used in Italy and across Europe for electronic invoices, certified email (PEC), contracts, and public administration records. An .m7m file is a container that bundles a document with one or more cryptographic timestamps (RFC 5544). Unwrap opens both and displays the content immediately.
  • System requirements Mac: macOS 27 “Golden Gate” or later, Apple Silicon. Windows: Windows 11, x64 or ARM64 processor. Android: Android 13 or later (smartphones and tablets). iOS / iPadOS: iOS 18 or later (iPhone and iPad, via TestFlight). Full details are on the download page.
  • Does my data leave the device? No: opening, extracting, and reading happen entirely on-device in local memory. Network access is only used on demand to download the Italian invoice stylesheet once, to run optional signature verification (OCSP/CRL and eIDAS Trusted Lists), to check for app updates (can be turned off), and to open external links.
  • How much does Unwrap cost? How is it supported? Unwrap is currently in beta and is completely free. To sustain independent development and ongoing maintenance costs, the app is and will be supported by voluntary donations (via an optional external PayPal link) and in-app advertising.
  • Which file types, formats, and verifications can the application open? (Technical details)

    Unwrap inspects raw file bytes (up to 256 MB) rather than trusting file extensions alone, and is built to handle cryptographic envelopes, electronic invoices, email messages, and office documents:

    1. Signed envelopes & containers

    Opens .p7m envelopes (CAdES / PKCS#7 SignedData) encoded in binary DER, Base64, and PEM, including indefinite-length BER structures.

    Handles nested envelopes (e.g. .pdf.p7m.p7m) up to 5 levels deep while listing signers for every layer, detached signatures (prompting for the original data file and verifying its cryptographic digest), timestamped .m7m containers (TimeStampedData, RFC 5544), and CAdES-T embedded timestamps. Supports RSA, RSA-PSS, and ECDSA signatures. (Encrypted EnvelopedData envelopes are not supported).

    2. Electronic invoices (IT & EU)

    FatturaPA (Italy): ordinary, public-administration, and simplified invoices (FPR12, FPA12, FSM10), rendered in A4 using official AssoSoftware or Italian Revenue Agency XSLT stylesheets, or viewable as raw XML.

    European formats (EN 16931 & national): built-in offline A4 rendering for UBL 2.1 (Peppol BIS 3.0, XRechnung UBL, OIOUBL, RO e-Factura, including Peppol SBDH envelopes), UN/CEFACT CII (XRechnung CII, France), Factur-X / ZUGFeRD 1.0 & 2.x (including extracting embedded XML from hybrid PDFs on Mac, Windows, and iOS), Facturae 3.2.x (Spain, including multi-invoice batches), and KSeF FA(2)/FA(3) (Poland).

    3. Email, PEC & extracted files

    Email & PEC (.eml, postacert.eml): parses MIME messages, displays headers, body (in a sandboxed view with no scripts or remote tracking images), and PEC certification metadata (daticert.xml), and opens any attachment directly.

    Built-in viewers: PDF (zoom, thumbnails, search, print), XML and JSON (pretty-printed with syntax highlighting), plain text (UTF-8, UTF-16 with BOM, Windows-1252), and images (PNG, JPEG, GIF, BMP, WebP, HEIC/AVIF up to 40 MP). Any other file type is extracted so you can save it or open it with its default app, with safety checks preventing accidental execution of programs or scripts (.exe, .bat, .apk, .sh).

    4. Cryptographic checks (on demand)

    Integrity & trust chain: recalculates the message digest and verifies each signer's mathematical signature; builds the certificate chain (fetching missing intermediate certificates via AIA) up to system trust roots or official eIDAS Trusted Lists (Italian AgID list or all EU member state lists, including historical service status intervals).

    Key usage, revocation & timestamps: checks certificate purpose constraints (Key Usage / EKU), queries OCSP responders and CRL distribution points for revocation status, and validates timestamps (CAdES-T and .m7m, including protected metadata and chained timestamps). Verification provides a detailed technical check and does not replace a legal LTV validation.
