Unwrap è in beta, sia su Mac sia su Windows. Su Windows può comparire un avviso all'avvio dell'installer: come installarla

Con un doppio clic mostra subito il contenuto: PDF, fattura elettronica impaginata, XML con sintassi colorata, testo o immagine — senza il solito giro verifica → estrazione → apertura con altri strumenti. Tutto elaborato in locale sul tuo computer, nessun file lascia il dispositivo. Su Mac si integra anche con il Finder: basta selezionare un .p7m e premere la barra spaziatrice per vederne l'anteprima con Quick Look, senza nemmeno aprire l'app.

Come iniziare

  • 1. Associa i file .p7m a Unwrap Su Mac, la prima volta, fai clic con il tasto destro su un file .p7m, scegli "Ottieni informazioni", apri la sezione "Apri con", seleziona Unwrap e fai clic su "Modifica tutti" per renderlo l'app predefinita. Da quel momento basterà il doppio clic per aprirlo sempre con Unwrap. Su Windows non serve questo passaggio: dopo l'installazione il doppio clic su un .p7m o .m7m apre già Unwrap.
  • 2. Estrai il contenuto in un attimo Una volta aperto il file, puoi salvare o trascinare fuori il contenuto (PDF, fattura, XML, immagine) in pochi secondi, senza passaggi intermedi.

Domande frequenti

  • Cos'è un file .p7m? È un documento (PDF, fattura elettronica, XML, immagine...) racchiuso in una "busta" firmata digitalmente secondo lo standard CAdES/PKCS#7, usato in Italia per fatture elettroniche, PEC e comunicazioni con la Pubblica Amministrazione. Unwrap apre la busta e mostra subito il contenuto.
  • RequisitiMac: macOS 27 "Golden Gate" o successivo, con Apple Silicon. Windows: Windows 11, processore x64 o ARM64.
  • Come installo la versione per Windows? Dalla pagina di download scarica Unwrap-…-win-x64-Setup.exe per i PC Intel/AMD oppure Unwrap-…-win-arm64-Setup.exe per i PC ARM64 (per esempio Snapdragon). L'installer non ha ancora una firma Authenticode: se Windows mostra «Windows ha protetto il PC», scegli «Ulteriori informazioni» e poi «Esegui comunque». Nelle note di ogni release trovi l'impronta SHA-256 per controllare il file scaricato.
  • I miei file lasciano il computer? No: l'estrazione e la lettura avvengono interamente in locale. La rete è usata solo per il foglio di stile delle fatture elettroniche, la verifica facoltativa della firma (OCSP/CRL), la ricerca degli aggiornamenti e il link "Dona".
  • Cos'è il banner donazioni? Un invito occasionale, disattivabile nelle Impostazioni, a sostenere volontariamente lo sviluppo tramite un link PayPal esterno. Non sblocca nessuna funzionalità.

One double-click shows the content right away: PDF, a nicely formatted e-invoice, syntax-highlighted XML, text or an image — instead of the usual verify → extract → open routine with other tools. Getting Started

  • 1. Associate .p7m files with Unwrap On Mac, the first time, right-click a .p7m file, choose "Get Info," expand "Open with," select Unwrap, then click "Change All..." to make it the default app. From then on, a double-click will always open it with Unwrap. On Windows this step isn't needed: after installation, double-clicking a .p7m or .m7m file already opens Unwrap.
  • 2. Extract the content in a snap Once the file is open, you can save or drag out the content (PDF, e-invoice, XML, image) in a few seconds, with no extra steps.

FAQ

  • What is a .p7m file? It's a document (PDF, e-invoice, XML, image...) wrapped in a digitally signed "envelope" following the CAdES/PKCS#7 standard, widely used in Italy for electronic invoices, certified email (PEC) and communications with public administration. Unwrap opens the envelope and shows the content right away.
  • RequirementsMac: macOS 27 "Golden Gate" or later, Apple Silicon. Windows: Windows 11, x64 or ARM64 processor.
  • How do I install the Windows version? From the download page, get Unwrap-…-win-x64-Setup.exe for Intel/AMD PCs or Unwrap-…-win-arm64-Setup.exe for ARM64 PCs (Snapdragon, for example). The installer doesn't have an Authenticode signature yet: if Windows shows "Windows protected your PC," choose "More info" and then "Run anyway." The notes of each release list the SHA-256 fingerprint to check the downloaded file.
  • Does my data leave the computer? No: extraction and reading happen entirely on-device. Network access is only used for the invoice stylesheet, the optional signature check (OCSP/CRL), the update check, and the "Donate" link.
  • What is the donation banner? An occasional, dismissible prompt (can be turned off in Settings) to voluntarily support development via an external PayPal link. It never unlocks any feature.
