Privacy Policy — Unwrap

Ultimo aggiornamento: novembre 2026

Unwrap è un'app per macOS e Windows che apre file .p7m (buste firmate CAdES/PKCS#7) e ne mostra il contenuto. Questa pagina descrive quali dati l'app tratta e come.

Nessuna raccolta dati

Unwrap non raccoglie, non trasmette e non vende alcun dato personale. Non ci sono account, non c'è analytics, non c'è tracciamento pubblicitario, non ci sono SDK di terze parti per la raccolta dati. L'app non sa chi sei e non ha modo di identificarti.

Elaborazione dei file

L'apertura e l'estrazione dei file .p7m avvengono interamente sul tuo computer; su Mac, usando solo il framework di sistema Security di Apple. I file che apri non lasciano mai il dispositivo. Il contenuto estratto resta in memoria e viene scritto su disco solo quando scegli tu di salvarlo, esportarlo o aprirlo con un'altra app.

Su Windows, anche «Mostra nella cartella» e il trascinamento verso altre app creano copie temporanee locali, in una cartella privata dell'app svuotata a ogni avvio.

Quando l'app usa la rete

Unwrap richiede l'autorizzazione di rete solo per queste funzioni, tutte facoltative o innescate da un'azione esplicita:

  • Fatture elettronicheAl primo utilizzo scarica una volta sola il foglio di stile pubblico per impaginare la fattura, e lo conserva in cache sul computer. La fonte è quella scelta nelle impostazioni dell'app: assosoftware.it oppure l'Agenzia delle Entrate (fatturapa.gov.it). Non viene inviato alcun dato del file, solo la richiesta di scaricare il foglio di stile.
  • Verifica firma… (funzione a richiesta): interroga i servizi OCSP/CRL degli enti certificatori e le Trusted List eIDAS per controllare la validità del certificato di firma del documento. Queste richieste riguardano il certificato del documento, non la tua identità.
  • Aggiornamenti dell'app su WindowsCon la frequenza che scegli nelle Impostazioni (di serie, una volta al mese; puoi scegliere ogni giorno, ogni settimana o mai), l'app legge un piccolo file dalla pagina delle release su GitHub. Non viene inviato alcun documento né informazioni sul tuo computer; come per ogni richiesta web, GitHub può vedere l'indirizzo IP. Se c'è una versione nuova, l'app la scarica e la installa solo se confermi, e rifiuta un aggiornamento con firma digitale non valida.
  • Aggiornamenti dell'app su Mac (solo nella versione scaricata dal sito, non in quella del Mac App Store): l'app controlla se esiste una versione più recente con Sparkle, un componente open source di aggiornamento. Con la frequenza che scegli nelle Impostazioni (di serie, una volta al mese; puoi scegliere ogni giorno, ogni settimana o mai), scarica un piccolo elenco pubblico da unwrapapp.it/appcast.xml. Non viene inviato alcun dato personale, alcun documento né informazioni sul tuo Mac (Sparkle non invia il «profilo di sistema»); come per ogni richiesta web, il server che ospita il file può vedere l'indirizzo IP. Se c'è una versione nuova, l'app la scarica da GitHub solo se confermi. Se scegli «Mai», l'app non fa alcun controllo finché non premi «Cerca aggiornamenti…». Ogni aggiornamento è verificato con una firma digitale prima di essere installato.
  • Link "Dona"Apre il browser di sistema su una pagina PayPal esterna, gestita da PayPal, non da Unwrap.

Se non usi queste funzioni (e, nelle versioni scaricate dal sito, se scegli «Mai» per gli aggiornamenti), l'app non effettua alcuna richiesta di rete. L'estensione Quick Look (anteprima nel Finder) non ha accesso alla rete.

Permessi del sistema

Su Mac, Unwrap gira in App Sandbox e accede solo ai file che apri esplicitamente (doppio clic, drag & drop, "Apri con" o selezione da finestra di dialogo). Non ha accesso generico al disco, non legge altri file o cartelle.

Su Windows, Unwrap è una normale applicazione desktop: l'installazione richiede la conferma dell'amministratore e l'app non gira in una sandbox. Le impostazioni sono salvate sul computer, nella cartella %APPDATA%\Unwrap.

Minori

Unwrap non è rivolta specificamente ai minori e non raccoglie consapevolmente dati di minori, in quanto non raccoglie dati da nessun utente.

Modifiche a questa policy

Eventuali aggiornamenti verranno pubblicati su questa stessa pagina, con la data di ultimo aggiornamento in cima.

Privacy Policy — Unwrap

Last updated: November 2026

Unwrap is a macOS and Windows app that opens .p7m files (signed CAdES/PKCS#7 envelopes) and shows their content. This page describes what data the app processes and how.

No data collection

Unwrap does not collect, transmit, or sell any personal data. There are no accounts, no analytics, no advertising tracking, and no third-party data-collection SDKs. The app has no way to identify you.

File processing

Opening and extracting .p7m files happens entirely on your computer; on Mac, using only Apple's system Security framework. Files you open never leave the device. Extracted content stays in memory and is only written to disk when you choose to save, export, or open it with another app.

On Windows, "Show in folder" and dragging to other apps also create local temporary copies, in a private app folder that is emptied at every launch.

When the app uses the network

Unwrap requests network access only for these features, all optional or triggered by an explicit action:

  • Electronic invoicesOn first use, it downloads the public stylesheet once to render the invoice, and caches it locally. The source is the one selected in the app's settings: assosoftware.it or the Italian Revenue Agency (fatturapa.gov.it). No file data is sent, only the request to download the stylesheet.
  • Verify signature… (on-demand feature): queries certificate authorities' OCSP/CRL services and the eIDAS Trusted Lists to check the validity of the document's signing certificate. These requests concern the document's certificate, not your identity.
  • App updates on WindowsAt the frequency you choose in Settings (by default once a month; you can pick daily, weekly or never), the app reads a small file from the GitHub releases page. No documents and no information about your computer are sent; as with any web request, GitHub can see the IP address. If a new version exists, the app downloads and installs it only if you confirm, and rejects an update with an invalid digital signature.
  • App updates on Mac (only in the version downloaded from the website, not the Mac App Store one): the app checks for a newer version using Sparkle, an open-source update component. At the frequency you choose in Settings (by default once a month; you can pick daily, weekly or never), it downloads a small public list from unwrapapp.it/appcast.xml. No personal data, no documents and no information about your Mac are sent (Sparkle does not send the "system profile"); as with any web request, the server hosting the file can see the IP address. If a new version exists, the app downloads it from GitHub only if you confirm. If you choose "Never", the app makes no check until you press "Check for Updates…". Every update is verified with a digital signature before it is installed.
  • "Donate" linkOpens the system browser to an external PayPal page, handled by PayPal, not by Unwrap.

If you don't use these features (and, in the versions downloaded from the website, choose "Never" for updates), the app makes no network requests at all. The Quick Look extension (Finder preview) has no network access.

System permissions

On Mac, Unwrap runs in an App Sandbox and only accesses files you explicitly open (double-click, drag & drop, "Open With", or a file picker). It has no generic disk access and does not read other files or folders.

On Windows, Unwrap is a regular desktop application: installation requires administrator confirmation and the app does not run in a sandbox. Settings are stored on your computer, in the %APPDATA%\Unwrap folder.

Children

Unwrap is not directed at children and does not knowingly collect data from children, as it does not collect data from any user.
